# Sorties

Chaque rendu crée un dossier `AAAAMMJJ-HHMMSS_<nom>/` contenant la vidéo MP4, une vignette JPG et le journal Blender.
Ces fichiers ne sont pas versionnés sur `main` (trop lourds) ; les rendus lancés depuis GitHub Actions sont publiés
sur la branche `resultats` et en artefact téléchargeable.
